title: Agents

An agent is a flat Clojure map used by the model/tool loop:

```clojure
(require '[karcarthy :as k])

(k/defagent reviewer
  {:model "gpt-5.6"
   :instructions
   "Review the patch. Report concrete defects and explain the evidence."})
```

`defagent` defines a var and derives the agent name from its symbol. Use
`agent` when constructing a value inside an expression:

```clojure
(def reviewer
  (k/agent
   {:name "reviewer"
    :model "gpt-5.6"
    :instructions "Review the patch."}))
```

Both forms create the same kind of value.

## Configuration

| Key | Meaning |
| --- | --- |
| `:name` | Agent name. `agent` requires it; `defagent` derives it. |
| `:description` | Tells another model when to call this agent. |
| `:model` | Model ID, model configuration, or context function. |
| `:instructions` | The complete model-visible instructions. |
| `:tools` | Tools the model may call. Include `k/eval` to allow authored Clojure. |
| `:agents` | Predefined agents the model may call. |
| `:context-schema` | Schema for local run context. |
| `:input-schema` / `:output-schema` | Input and output boundaries. Both default to `string?`. |
| `:input-guardrails` / `:output-guardrails` | Functions that check input and output. |
| `:max-turns` | Maximum model turns for one call. |
| `:limits` | Limits that may narrow the active run. |

karcarthy sends `:instructions` exactly as provided. It does not prepend a
framework prompt. The descriptions of configured tools, including eval, are
sent separately as model-callable capabilities.

`:model`, `:instructions`, `:tools`, and `:agents` may be functions of the
current run context.

## Predefined and authored agents

An agent listed in `:agents` already exists before the parent runs:

```clojure
(k/defagent reviewer
  {:model "gpt-5.6"
   :instructions "Review the patch and ask the verifier to check findings."
   :agents [verifier]})
```

The parent model may call `verifier`, but it does not define it.

An agent with `k/eval` can instead construct a new agent after reading its
input:

```clojure
(k/defagent reviewer
  {:model "gpt-5.6"
   :instructions "Choose and author the specialist needed for this patch."
   :tools [k/eval]})
```

The eval tool description teaches the model the `agent` form and makes the
current input available as `input`. See [Eval](/docs/reference/eval).

## Schemas and guardrails

Input is checked before the first model request. Output is checked before the
agent completes.

Guardrails receive the local run context and the value:

```clojure
{:input-guardrails
 [(fn [run-context value]
    (allowed-request? (:context run-context) value))]
 :output-guardrails
 [(fn [_ value]
    (grounded? value))]}
```

A schema or guardrail failure produces a structured failed run.

## Definitions and values

`agent` and `defagent` retain the original form and its macroexpansion:

```clojure
(k/definition reviewer)
(k/expansion reviewer)
```

The resulting agent is still ordinary data:

```clojure
(:instructions reviewer)
(assoc reviewer :instructions "Return only verified findings.")
```

There is no hidden configuration object or separate representation for agents
created by a model.
