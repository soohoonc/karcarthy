---
title: Events and monitoring
description: Observe runs, agents, model calls, tools, sessions, and eval.
---

Pass an event handler to `run!`:

```clojure
(def seen (atom []))

(def result
  (k/run! reviewer input
          {:on-event #(swap! seen conj %)}))
```

Or display a live tree:

```clojure
(def live (k/monitor {:display :tree}))
(def result (k/run! reviewer input {:on-event live}))
```

```text
run run_7c2e9b… · running · 51s · 7 model calls · 2 evals
└─ reviewer
   ├─ security-reviewer
   └─ verifier
```

`(k/monitor live)` prints the latest tree again. `(k/monitor-state live)`
returns the event-derived data. One monitor may observe several runs.

## Event names

| Family | Events |
| --- | --- |
| run | `:run/started`, `:run/completed`, `:run/failed`, `:run/cancelled` |
| agent | `:agent/started`, `:agent/completed`, `:agent/failed` |
| model | `:model/requested`, `:model/text-delta`, `:model/tool-call-delta`, `:model/stream-event`, `:model/completed`, `:model/failed` |
| tool | `:tool/approval-requested`, `:tool/approval-resolved`, `:tool/approval-reused`, `:tool/started`, `:tool/completed`, `:tool/failed` |
| session | `:session/updated` |
| eval | `:eval/started`, `:eval/expanded`, `:eval/completed`, `:eval/failed` |

Every event has `:karcarthy/type :event`, `:type`, `:time-ms`, and `:run-id`.
Agent-scoped events also have `:agent-id`, `:parent-id`, and `:depth`. Tool
events include `:tool-call-id` where applicable.

Only the first `run!` emits run lifecycle events. Nested agent calls emit their
own agent, model, tool, and eval events under the same run ID.

## Inspect eval

The expanded event retains the expression the model wrote and the result of
macroexpansion:

```clojure
(->> (k/events result)
     (filter #(= :eval/expanded (:type %)))
     (map #(select-keys % [:expression :expansion :namespace])))
```

The relevant fields are:

| Event | Fields |
| --- | --- |
| `:eval/started` | `:code`, `:input` |
| `:eval/expanded` | `:expression`, `:expansion`, `:namespace` |
| `:eval/completed` | `:value`, `:duration-ms` |
| `:eval/failed` | `:phase`, `:error`, `:duration-ms` |

## Emit application events

Tools and evaluated Clojure may add events:

```clojure
(k/emit! {:type :application/decision
          :decision :retry})
```

karcarthy supplies the run and agent lineage. Conflicting lineage fields in the
application event are ignored.

## Retained and live-only events

`k/events` returns retained lifecycle and application events. Model text,
tool-call, and raw stream deltas are sent through `:on-event` but are not kept
in the completed run.

Event handlers are best-effort observers. An exception in a handler does not
fail the agent.
